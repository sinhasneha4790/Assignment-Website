Folk & Form — website design (plain HTML export)
================================================

HOW TO VIEW
1. Unzip this folder anywhere on your computer.
2. Double-click  index.html  (the home page) or  pages.html  (a list of every page).
3. Click around: links between pages, the home carousel, size and colour buttons,
   cart quantities, payment options, the booking calendar and help topics all work.

Works offline. An internet connection only loads the two web fonts (Fraunces and Manrope);
without it the pages fall back to similar system fonts.

WHAT'S INSIDE
  index.html ............ Home (with the sliding carousel)
  hub-women.html ........ Women / Men / Teens hub (Professional / Casual switch)
  listing.html .......... Category listing with filters
  search.html ........... Search results
  product.html .......... Product page
  size-guide.html ....... Size guide panel
  cart.html, checkout.html, confirmation.html, payment-failed.html
  login.html, account.html, order-detail.html, profiles.html
  styling.html, booking.html, booking-confirm.html
  help.html, about.html, 404.html, admin.html
  mobile-home.html ...... Phone version of the home page
  header.html, footer.html  (shared parts, shown on their own)
  assets/ ............... styles (ff.css, responsive.css) and the small page script (dc-runtime.js)
  images/ ............... the 34 illustrations used as stand-in product photos

FOR CLAUDE CODE
Copy this whole folder into the project as  /design-reference  . It is the visual
reference for the build described in "Folk & Form — Technical Build Spec for Claude Code".
Prices, names and policies here are sample data; the illustrations are placeholders
for real product photos.
